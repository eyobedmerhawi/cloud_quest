## Project Reflection

For this assignment, I worked on building a Flutter app using Firebase Authentication, Firestore, Cloud Functions, and Genkit AI. I was able to create the login and signup screens, retrieve a daily challenge, and implement backend functions for completing challenges and asking an AI coach questions.

The biggest challenge was getting all the Firebase services to work together. Authentication and Firestore worked during my initial testing, but I later ran into connection issues with the Android app. I also successfully connected Genkit to Gemini, but the AI Coach function timed out during testing.

I learned more about Firebase security rules, using emulators, and keeping user rewards controlled by backend functions instead of the app. Although I couldn't finish testing every feature, this assignment helped me better understand how Flutter applications communicate with cloud services.
